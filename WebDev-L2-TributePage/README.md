# Dr. A. P. J. Abdul Kalam - Tribute Page

## Project Overview

This project is a responsive tribute page dedicated to Dr. A. P. J. Abdul Kalam, an Indian aerospace scientist, author and former President of India.

The page was created as part of the Oasis Infobyte Web Development Internship, Level 2, Task 2.

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- Responsive CSS

## Features

- Hero section with title and tagline
- Prominent image of Dr. A. P. J. Abdul Kalam
- Biography section with original paraphrased content
- Key achievements section
- Timeline of important events
- Distinctive quote section
- Multiple background colours
- Multiple font styles
- Responsive layout for desktop, tablet and mobile screens
- Image attribution
