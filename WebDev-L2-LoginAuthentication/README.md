# SecureAuth - Login Authentication System

## Project Overview

SecureAuth is a responsive Login Authentication System developed using HTML, CSS and JavaScript.

The application allows users to create an account, securely store their password as a SHA-256 hash, log in using their credentials and access a protected dashboard.

This project was created as part of the Oasis Infobyte Web Development Internship, Level 2, Task 4.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Crypto API
- Local Storage
- Session Storage
- Google Fonts

## Features

- User registration
- Email validation
- Password validation
- Minimum 8-character password requirement
- Password must contain at least one number
- Confirm password validation
- Duplicate email detection
- SHA-256 password hashing
- Login authentication
- Generic invalid credentials message
- Protected dashboard
- Session management
- Logout functionality
- Responsive design
- Mobile-friendly interface
