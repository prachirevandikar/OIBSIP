# Calculator

## 📌 Project Overview

This project is a browser-based calculator developed as part of the Oasis Infobyte Web Development Internship.

The calculator provides a simple and interactive interface for performing basic arithmetic operations such as addition, subtraction, multiplication, and division.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- User-friendly calculator interface
- Addition, subtraction, multiplication, and division
- Decimal number calculations
- Clear (`C`) button
- Backspace (`⌫`) button
- Equals (`=`) button
- Division-by-zero error handling
- Interactive button hover and click effects
- Responsive layout
