# Task 1 - Calculator

## Project Overview

The Calculator is a browser-based calculator application designed to perform basic arithmetic operations through an interactive button interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal number support
- Clear function
- Backspace function
- Result display
- Division-by-zero error handling
- Interactive button interface
- Responsive design
