# TaskFlow - To-Do Web App

## Project Overview

TaskFlow is a responsive and interactive To-Do Web Application developed to help users organize and manage their daily tasks.

The application allows users to add, complete, edit and delete tasks. It also provides separate views for all, pending and completed tasks.

This project was created as part of the Oasis Infobyte Web Development Internship, Level 2, Task 3.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Google Fonts

## Features

- Add new tasks
- Mark tasks as completed
- Edit existing tasks
- Delete tasks
- View all tasks
- Filter pending tasks
- Filter completed tasks
- Display total, pending and completed task counters
- Display task creation time
- Empty-state messages
- Local Storage support
- Responsive design
- Mobile-friendly interface
- Form validation
- Edit task modal
